# RUSLE: Revised Universal Soil Loss Equation on Google Earth Engine
Interactive tools and scripts to estimate average annual soil loss (A) using Earth Observation datasets on Google Earth Engine (GEE).
Formula: A = R * K * LS * C * P
- R: Rainfall erosivity factor (from CHIRPS / WorldClim)
- K: Soil erodibility factor (from SoilGrids)
- LS: Slope length and steepness factor (from SRTM / Copernicus DEM)
- C: Cover management factor (from Sentinel-2 / Landsat NDVI)
- P: Support practice factor
